# 内置基础行为模型与复现实验

发布版本：`base_v4_20261111_r2`。训练和评测实际运行于2026-11-11，所有输入和标签均为合成数据。真实参与者和真实反馈会话均为0。

## 软件如何使用

标准后端启动优先加载可用的当前schema个人模型；缺少可用个人模型时，加载[基础模型资源](../../backend-next/src/mindflow/resources/base-v4/)。API以 `mode=base`、`model_origin=bundled_base` 和 `inference_available=true` 标明来源，个人验证状态仍为 `ready=false`、`personalized=false`。

基础模型使用独立的 `models/bundled/<version>/` 缓存与本机HMAC签名，个人模型指针仍位于 `models/v2/`。发布清单摘要、模型字节摘要、依赖版本和特征顺序均通过校验后才加载。`MINDFLOW_BASE_MODEL_ENABLED=False` 可关闭基础回退。

## 数据与评估

- 145,152个五分钟窗口，18类角色、108个模拟身份。
- 104个实际软件/网站与1个未知条目，30种情境、22,255个连续会话。
- 28个模拟日期、8种固定UTC偏移、全天24小时与每周7天。
- 有标签训练窗口59,684个，独立模拟身份历史校准窗口14,662个。
- 休息、离开、未知、混合意图和输入缺失等26,794个窗口不进入二元监督和准确率分母。

所有28维特征均由生产特征提取器从模拟前台活动、30秒输入桶和浏览器时间段计算。身份、职业、软件名称、情境名称与标签只作审计元数据，不输入分类器。

模型固定为RF+XGBoost与独立身份的sigmoid校准，测试集不参与超参或模型选择。未知身份测试按模拟身份隔离；未来日期测试严格晚于训练和校准时刻。完整的合成指标快照含六算法对照、角色与情境切片、模拟身份重采样区间和数据审计，见[结果JSON](base-v4-results.json)。

## 已知困难场景

[模型卡](../../backend-next/src/mindflow/resources/base-v4/model_card.md)保留了游戏测试、客服、工作软件内目标偏离和无关阅读的困难结果。以未见模拟身份为例，游戏测试误分类率为61.29%，工作软件内目标偏离召回仅0.43%。相同工具和输入轨迹可服务于不同意图，后续需本人目标、纠正反馈及独立真实场景验证。

模拟身份留出仍共享场景配方。本轮成绩描述生成分布内的泛化；未见模板、真人试用、端到端通知和竞品同条件测试属于下一阶段。

## 完整复现

在仓库根目录执行：

```powershell
cd backend-next
uv sync --locked --extra dev --extra ml
uv run python scripts/run_experiments.py --base-model --run-id YOUR_NEW_RUN_ID
```

运行结果写入 `backend-next/data/experiments/YOUR_NEW_RUN_ID/`，包含完整合成窗口、CSV特征、每窗口预测、数据审计、模型和报告。此模式不会读取个人数据库。固定随机种子为20261110，每角色6个身份，每身份28天、每天48个五分钟窗口。重新构建发布包时需传入一个新的 `--base-bundle-dir`，并同步更新加载器固定的清单摘要与版本；发布目录已有内容时停止覆盖。

已有模型的实际启动与测试：

```powershell
uv run python -m mindflow.main
uv run python -m pytest tests/test_base_bundle.py tests/test_base_synthetic.py -q
```

## 个人数据个性化

积累自己的会话反馈和窗口标签后，通过模型中心或以下命令重训并校准个人分类器：

```powershell
uv run python -m mindflow.train --source db --use-window-labels
```

个人训练沿用日期前向评估、唯一会话计数、独立校准和发布一致性检查；自动训练保持shadow-only。这里的个性化采用行为分类器重训与校准。

## 发布验证记录

本轮全后端测试3419通过、4跳过，Ruff通过，严格mypy在195个源文件上通过；前端构建通过。另验证了基础模型冷启动、旧schema/未就绪个人模型回退、个人模型接管、shadow保留基础模型、本机签名校验及固定留出样例的发布概率一致性。Python wheel已确认包含三个模型制品、清单、模型卡和固定预测样例。

r1审计发现27个输入活跃秒数超过非空闲秒数的反例；r2修复桶级物理时长约束后，按相同种子、标签与超参重训。首轮仅作历史记录，随软件发布的版本为r2。
