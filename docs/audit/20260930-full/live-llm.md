## 内容可信度边界

连接、调用、schema 和未降级通过，不代表全部自然语言内容都正确。
无历史消息、无证据工具的普通聊天样例出现了声称掌握用户历史行为的推断，
而输入未提供相应证据。这是无证据烟测样例的内容观察，
不是已定位的生产 HTTP 代码缺陷。未据此修改生产提示词或降低门槛。
HTTP 补验明确要求不推断历史、不查询个人数据，返回通用建议，未调用工具。

面板文本引用检测为 0/0，不能声称非空引用已全部验证。
多场景重复、长期稳定性、对抗提示词、全部内容的事实与证据绑定尚未验收。
个人模型兼容性和质量结论不因 LLM 补验改变，见 [总验收报告](acceptance.md)。
