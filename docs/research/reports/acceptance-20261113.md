# 论文 RAG 接入验收

日期：2026-11-13。发布代码基于远端 `c84b090`，本轮未修改前端或模型权重。

## 与既有提交的关系

`5bff9d6` 已有理论驱动提示词、行为证据和解释界面改进；`c84b090` 将默认云服务切换为 ChatECNU。两项历史改进没有建立本轮带 PDF 页码的论文检索库。本次新增的是实际文献入库、检索、生成上下文注入和当轮引用集合校验。

## 取得与构建

研究工作区的23项候选中，21份PDF通过文件头、正文提取、SHA-256、页数和标注锚点检查；18份本轮取得，3份复用原件，2项不可用。

现用语料为21份来源、27张原创释义卡和187个审阅页原文块。原件及私人SQLite索引留在研究工作区；公开仓库维护来源元数据、文件指纹、释义卡与构建脚本。

每块最多1200字符，重叠160字符，不跨物理页。只索引经过审阅的页，Eckert博士论文载体中的其他章节不会被当作该篇投稿稿件。

## 这些结果支持什么

这些检查支持语料可定位、检索器按声明运行、消息构建实际包含文献和错误引用按既有路径回退。开发查询参与了工程调试，不是独立保留测试集；hit@3不等于完整召回率。

本轮没有付费模型生成、新的基础模型训练或真人效果实验。ID合法不等于原文支持该句；建议支持度还需盲评，任务收益和打扰负担还需用户研究。基础分类器的合成BA与上述结果分别报告。

运行中的常驻后端需要重启后才会一致加载新代码。本报告不把代码回归通过写成常驻进程已刷新，也不把Git推送写成GitHub Pages运行后端。
